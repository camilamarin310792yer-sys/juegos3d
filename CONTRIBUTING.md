# Guía de contribución

¡Gracias por querer mejorar el proyecto!

1. Haz un *fork* del repositorio.
2. Crea una rama descriptiva: `git checkout -b mejora-animaciones`
3. Realiza tus cambios manteniendo el estilo del código (nombres en español, funciones con docstring).
4. Prueba el juego ejecutando `python main.py`.
5. Haz *commit*: `git commit -m "Agrega animaciones de caída"`
6. Sube tu rama y abre un *Pull Request* explicando qué cambió y por qué.

## Reportar errores

Abre un *Issue* con: sistema operativo, versión de Python y Pygame, pasos para reproducir el error y, si es posible, una captura de pantalla.
